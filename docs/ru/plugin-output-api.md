# Plugin API 1.2: управление выводом и плеерами

Доступно начиная с GMIB 5.7.1. Плагин с новыми методами указывает `gmibApi: "^1.2.0"`. Более старые
хосты отклоняют такой манифест до запуска. Ранее опубликованные плагины с `^1.0.0` и `^1.1.0`
продолжают работать. В SDK новые методы помечены необязательными, чтобы переносимый код мог
проверить их наличие до вызова. Интерфейс управления удалённым GMIB проверяет версию хоста:
установка, обновление, включение и открытие пульта плагина с `player.control` недоступны на хостах
ниже 5.7.1; отключение и удаление остаются доступны.

## Разрешения

- `output.control`: `context.output.listScreens/getStatus/start/stop`.
- `player.control`: `context.output.listPlayers/setPlayerState`.

Разрешения независимы и проверяются при каждом вызове. Одного `output.control` недостаточно для
доступа к плеерам. Для сценария «часы рядом с рекламой» нужны оба. Установка или обновление плагина
с новым разрешением требует принятия точного набора разрешений обычным диалогом GMIB. Доступ к БД
GMIB или произвольным внутренним HTTP-маршрутам плагину не предоставляется.

## Методы

```ts
await context.output.listPlayers();
// [{ id: 7, name: "Реклама", playing: false }]

await context.output.setPlayerState({ playerId: 7, playing: true });
await context.output.setPlayerState({ playerId: 7, playing: false });
```

`playing` в списке отражает сохранённый флаг автоматического воспроизведения; это не подтверждение
физического изображения на дисплее.

При `playing: true` хост проверяет плеер и выбранный плейлист, сохраняет состояние воспроизведения,
при необходимости создаёт локальный плеер скрытым и показывает его настроенные окна вывода. Главная
вкладка/окно GMIB не активируется и не разворачивается. Существующий плеер используется без
повторного открытия вкладки. При ошибке создания плеера исходное состояние воспроизведения
восстанавливается. При `playing: false` хост останавливает воспроизведение, сбрасывает текущий
элемент и скрывает окна вывода этого плеера; вкладка плеера не закрывается. Геометрия окон и
плейлисты настраиваются штатными средствами GMIB.

Метод возвращает `Promise<void>`. Ошибки: нет разрешения, некорректные аргументы, плеер удалён,
плейлист не выбран, локальный хост ещё не готов, запуск или сохранение не удались. Успех означает
применение состояния, но не гарантирует наличие подключённого физического дисплея или
воспроизводимого файла.

Методы `start`, `stop` и `setPlayerState` выполняются последовательно для каждого экземпляра
плагина. Между несколькими вызовами нет общей транзакции: плагин должен сериализовать составную
команду и обрабатывать частичные ошибки. Разные плагины могут управлять одним плеером; эксклюзивной
блокировки плееров в API 1.2 нет.

## Эксклюзивный экран

`output.start({ screenId, pageId, autoStart })` сначала скрывает все прежние экраны этого плагина,
затем включает выбранный. Чужие плагины не отключаются; занятый чужим плагином целевой экран
приводит к ошибке. `output.stop()` очищает все экраны, принадлежащие плагину. Это не останавливает
плееры автоматически: вызывайте `setPlayerState` для управляемого плеера явно.

`output.getStatus().active` учитывает назначение страницы, подключение дисплея и фактическую
видимость окна. Показ экрана выполняется через `showInactive`. Явный показ плагином действует на
выбранные экран и плеер даже после глобального скрытия; другие окна остаются скрыты. Следующая
глобальная команда видимости GMIB снова имеет приоритет. На Wayland отсутствие фокусировки зависит
от ограничений Electron/оконного менеджера.

## Пример переключения

```ts
// Компактный экран и реклама рядом.
await context.output.stop();
await context.output.start({ screenId: 2, pageId: 'screen', autoStart: true });
await context.output.setPlayerState({ playerId: 7, playing: true });

// Широкий экран.
await context.output.setPlayerState({ playerId: 7, playing: false });
await context.output.stop();
await context.output.start({ screenId: 1, pageId: 'screen', autoStart: true });
```

При автозапуске `output.start` восстанавливается хостом из профиля `gmib.output`. Привязку плеера и
составную команду автозапуска плагин хранит и восстанавливает сам.
